## 操作与玩法

### 操作

| 操作 | 键位 |
| --- | --- |
| 跳跃 / 二段跳 | `空格` / `↑` / `W` |
| 下蹲 / 空中快速下落 | `↓` / `S` |
| 疾风冲刺（能量满时） | `K` / `J` / `Shift` |
| 暂停 / 继续 | `Esc` / `P` |
| 静音开关 | `M` |
| 结算界面重开 | `Enter` / `R` / 按钮 |

触屏设备会显示「跳跃 / 下蹲 / 冲刺」三个虚拟按钮；下蹲与跳跃支持长按/点按。

### 核心循环

- 角色自动向右奔跑，速度从 13.5 m/s 随距离平滑提升到 30.5 m/s，坐骑再叠加被动倍率。
- 跳跃带 0.1 秒 coyote time 和 0.14 秒输入缓冲；空中可再按一次二段跳。
- 障碍物：尖刺、晶体箱、横杆、激光闸、可踩踏史莱姆。横杆/激光需要下蹲，尖刺/箱子需要跳跃，史莱姆可从上方踩踏并反弹。
- 金币形成直线、抛物线、之字与环形阵列；连续吃币累计连击，连击倍率最高 ×5。
- 表现分由距离、金币、踩怪、冲刺撞碎障碍与奖励倍率共同组成。
- 死亡后首次复活免费；再次复活消耗 150 金币银行金币。复活生成安全跑道并获得 2.5 秒无敌与护盾。
- 本地存档保存最高表现分、最远距离、金币银行、总局数、坐骑/宠物选择和静音状态。

### 奖励模式

- **超级奖励**：金币充满「超级奖励」能量条后自动进入独立黄金场景，12 秒、表现分 ×3、密集金币阵列，结束额外 +1200 表现分并返回主赛道。
- **穿越奖励**：主赛道中会出现紫色的穿越之门，撞入后切换为独立的高速时空隧道场景，8 秒、速度 46 m/s、表现分 ×4，结束额外 +1800 表现分并返回主赛道。
- 两种奖励都会真正切换世界生成器、环境色板/天空/雾/灯光、镜头与 HUD 横幅，而不是简单换背景。

### 坐骑、宠物与道具

- 坐骑：疾风滑板（速度 +8%）、星翼滑板（跳跃 +10%），在开始界面选择并保存。
- 宠物：星尾狐（每 0.32 秒自动吸附 3.2 米内金币）、护卫蜂（开局护盾，之后每 26 秒补充）。
- 道具：金币磁铁 8 秒、护盾抵挡一次撞击、双倍表现分 10 秒。
- 技能：收集金币积累冲刺能量，满 100% 后按 `K` 进入 1.35 秒无敌冲刺，撞碎障碍并短暂提速。

## 架构

```text
src/
├── main.js          # Renderer、场景、主循环、错误边界与 WebGL 上下文丢失处理
├── game.js          # 状态机、物理循环、碰撞、计分、奖励切换、存档与 UI 同步
├── player.js        # 低多边形角色/坐骑/宠物、物理、姿态动画、护盾与影子
├── world.js         # 无限程序化关卡、图案库、对象池、InstancedMesh 金币场
├── environment.js   # 天空 shader、雾、灯光、四主题视差层、超级/穿越独立场景
├── camera.js        # 多模式机位、FOV 随速度变化、trauma 镜头抖动
├── particles.js     # 单 draw call 的 GPU 粒子池（金币火花、尾迹、爆裂、彩纸）
├── audio.js         # WebAudio 程序化音效与 32 步循环背景音乐
├── ui.js            # 开始/HUD/暂停/复活/结算/奖励横幅/Toast
├── assets.js        # 共享几何体/材质与障碍、拾取物、传送门工厂
├── input.js         # 键盘 + 触屏输入、跳跃缓冲
├── save.js          # localStorage 存档
├── config.js        # 数值、主题、坐骑/宠物配置
└── styles.css       # 全部 UI 视觉与响应式布局
```

关键技术点：

- **状态机**：`menu → playing ⇄ paused → dead → revive / gameover`，场景模式 `main ⇄ super / travel`；暂停、奖励、死亡、结算互斥，过渡使用黑场淡入淡出。
- **程序化关卡**：图案库包含安全段、金币段、跳跃、下蹲、坑洞、怪物、道具与组合障碍；坑宽被限制在 3.2–5.8 米，低于起始速度下的 8.3 米跳跃距离，并保留足够的起跳与落地缓冲，保证随机地图可通。
- **碰撞**：玩家 AABB 随下蹲改变高度；障碍使用相对屏幕坐标的盒体；踩踏判定优先于受伤；护盾/冲刺/复活无敌分层处理。
- **性能**：金币使用单 `InstancedMesh`，粒子使用单 `Points` 自定义 shader，障碍/地板/拾取物/装饰全部对象池化；关闭阴影、像素比上限 2、共享几何体与材质。50 秒长跑采样 draw calls 约 80，几何体 162，纹理 0。
- **环境**：Canvas 无纹理的天空 shader 渐变 + 雾 + 半球光/方向光；四套主题颜色、视差层与洞顶按主题切换并平滑插值；奖励场景有独立的太阳/云层/金币环与时空隧道环、星尘、速度线。
- **音频**：所有音效由振荡器与噪声实时合成；背景音乐为 112 BPM 的 32 步循环（低音、琶音、底鼓、踩镲），首次用户手势后启动，静音状态持久化。
