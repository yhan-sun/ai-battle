## 操作与玩法

| 动作 | 键盘 | 移动端 |
| :--- | :--- | :--- |
| 跳跃 / 二段跳 | `空格` / `W` / `↑` | 右侧触控区 |
| 切换车道 | `A` / `D` / `←` / `→` | 中间触控区 |
| 下蹲滑行 / 空中俯冲 | `S` / `↓` | 左侧触控区 |
| 冲刺技能 | `F` / `Shift` | 底部技能按钮 |
| 暂停 / 静音 | `P` / `Esc` / `M` | 右上角按钮 |

- **三车道**：左右切换车道躲开高墙，跳跃越过矮栏，下蹲钻过低空横梁。
- **怪物踩踏**：下落时踩中怪物可弹跳连踏，得分并积累连击。
- **坐骑 / 宠物**：跑满 800m 自动骑乘悬浮艇（跳跃与踩踏增强）；小精灵随距离升级，满级提供更强光效与吸附。
- **技能**：冲刺（无敌破障加速）；道具磁铁（金币自动吸附）、护盾（抵挡一次碰撞）。
- **超级奖励**：独立金色星空场景、密集金币阵列、表现分 ×2、22 秒倒计时，结束后返回主赛道。
- **穿越奖励**：真正切换为紫色高速隧道场景、整体提速 2.5 倍，穿越光门连续得分，14 秒后返回。
- **死亡复活**：死亡后最多 3 次原地复活（保留分数继续跑）。
- **存档**：最高分自动写入 `localStorage`。

## 架构

```
src/
├── main.js      # 入口，初始化 Game
├── game.js      # 状态机（菜单/跑酷/超级奖励/穿越奖励/暂停/死亡）、碰撞、分数、复活
├── world.js     # 场景、相机、灯光、视差远山、主题切换（白天/黄昏/地下/奖励/穿越）、镜头震动
├── level.js     # 无限程序化关卡：障碍/怪物/金币/道具/光门模板与金币阵列生成
├── player.js    # 角色程序化动画、跳跃物理（土狼时间）、坐骑、宠物、磁铁/护盾/冲刺
├── particles.js # 零分配对象池粒子系统
├── audio.js     # WebAudio 全合成音效与 BGM（无外部音频资源）
├── input.js     # 键盘 + 移动端触控区，跳跃预输入
├── ui.js        # HUD、开始/暂停/结算界面、道具计时条、Toast
└── config.js    # 全局平衡参数
```

关键技术：状态机驱动的模式切换、AABB 碰撞与踩踏判定、程序化关卡生成保证可通过性、对象池粒子、WebAudio 实时合成、FOV 冲刺拉伸与镜头震动。
