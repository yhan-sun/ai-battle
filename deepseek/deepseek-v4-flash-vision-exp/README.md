## 操作与玩法

| 动作 | 键盘 | 移动端 | 说明 |
| :--- | :--- | :--- | :--- |
| 跳跃 | 空格 / W / ↑ | 触摸「跳」 | 支持二段跳；骑上滑板后三段跳 |
| 下蹲 | S / ↓ | 触摸「蹲」 | 贴地滑行穿越低空横梁；空中触发俯冲速降 |
| 技能冲刺 | F / Shift | 屏幕技能条蓄满后触发 | 无敌冲刺，撞碎障碍并全图吸币 |
| 暂停 / 静音 | Esc / P / M | 右上角按钮 | 随时暂停、继续或静音 |
| 开始 / 重开 | Enter / R | 界面按钮 | 主菜单开始，游戏中快速重开 |

- **地形**：无限程序化生成，平台 / 深渊交错，随机组合箱堆、高柱、下蹲横梁、地刺、地面爬行怪（可踩踏）、飞行怪（下蹲躲避）；关卡设计保证随机地图全部可通过（深渊宽度不超过跳跃能力上限）。
- **道具**：磁铁（全图吸币）、护盾（挡一次伤害）、冲刺道具、坐骑「赛博滑板」（三段跳 + 14% 加速，受击掉落坐骑）。
- **超级奖励**：主赛道每集满 60 金币点亮★超级奖励门，穿过进入独立云端金币平台，金币阵列（弧线/蛇形/高空直线），`x6` 表现分倍率，22 秒时限，结束或走到底自动返回。
- **穿越奖励**：每 850 米点亮穿越之门，穿过进入超光速霓虹隧道（真实切换的高速场景：立体隧道环、三列金币墙、`x2.05` 速度、FOV 拉伸），16 秒后淡出返回。
- **死亡复活**：每局 1 次免费复活机会（复活后原地继续 + 4 秒无敌）；结算面板含表现分、距离、金币、最高纪录与 localStorage 存档。

## 架构

```
src/
├── main.js      状态机(Game State) · 主循环 · 碰撞裁决 · 计分 · 存档
├── config.js    全部数值常量与调色（集中调整）
├── world.js     场景 · 灯光 · 雾 · 四层视差背景(星/山/城/云/路侧霓虹)
├── player.js    程序化角色动画 · 二/三段跳 · 下蹲 · 磁铁/护盾/冲刺计时
├── level.js     无限程序化关卡 · 实体对象池 · 地形/障碍/金币/道具/奖励门
├── bonus.js     超级奖励与穿越奖励的独立 3D 场景与切换
├── audio.js     WebAudio 全程序化合成音效 + 8 小节循环 BGM（主赛道/奖励关两套）
├── particles.js 零 GC Sprite 粒子池
├── ui.js        HUD/开始/暂停/结算/触屏控制
└── style.css    霓虹风 UI 样式
```

- 碰撞：2.5D AABB 简化模型（J 型判定：下落踩怪弹性判定，站立/下蹲两种高度）。
- 支持对象池（地台/障碍/金币/粒子）、共享几何与材质、视口外实体回收。
- 随机地图可通行性由生成约束保证（深渊 ≤ 5.2m < 最低速单跳距离）。
