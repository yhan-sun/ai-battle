# Anthropic · Claude Fable 5 — 星尘酷跑 Star Dash Runner

> 参赛模型：Anthropic Claude Fable 5

天天酷跑风格 2.5D 横版跑酷,Three.js + Vite 从零实现,全部美术/音效代码生成,无外部资源。

## 运行

```bash
npm install
npm run dev
```

打开输出的 Local 地址即可玩。构建:`npm run build` / 预览:`npm run preview`。

## 操作

- 跳跃/二段跳:空格 / ↑ / W / 点击画面 / 上滑 / 右侧⬆按钮
- 下蹲/滑铲/空中速降:↓ / S / 下滑 / 右侧⬇按钮
- 技能「星尘爆裂」:F / ⚡按钮(3s无敌冲刺,CD 18s)
- 暂停:P / Esc / ⏸ • 静音:M

## 玩法

- 自动奔跑 + 速度随距离递增(12→30),表现分=距离+金币+踩怪
- 障碍:尖刺/双刺(跳)、悬空板(蹲)、高柱(大跳/二段跳)、深渊(跳)、怪物(踩头消灭+弹跳,撞上即死)
- 道具:🧲磁铁8s 🛡护盾12s(挡一次) 🚀冲刺3s无敌 ⭐星角兽骑乘+抵挡一次 🌀穿越门
- 坐骑/宠物:主页可开关,宠物自带小范围吸币,坐骑可抵挡一次
- S能量:吃25币攒满→**超级奖励**(独立金色场景、纯金币阵列、x4倍率、9s无敌、计时结束返回)
- 穿越门→**穿越奖励**(独立高速隧道场景、x1.6速度、光环+专属刷币/障碍、10s结束返回+2s无敌)
- 死亡:护盾/坐骑可保一次,否则结算;每局可复活1次(3s无敌冲刺)
- 存档:最高分/最远/最多金币/localStorage,开始/暂停/结算/新纪录全套UI
- 表现:合成音效+BGM、粒子(尘/金币/爆炸/拖尾)、镜头震动、FOV冲刺拉伸、视差远山/云/隧道光环/洞窟钟乳石、程序化角色跑跳蹲骑乘动画

## 架构

- `src/main.js` 启动+输入/触屏/手势接线
- `src/game.js` Game状态机(MENU/PLAYING/PAUSED/OVER)×奖励模式(normal/super/cross)、碰撞(AABB)、镜头、计分、复活
- `src/level.js` 无限分块程序化生成(平原/天空浮岛/洞窟)+对象池+主题换肤+奖励金币阵,最小间距/最大坑宽保证可通过
- `src/player.js` 程序化角色/坐骑/宠物+物理(土狼时间/跳跃预输入/空中速降)+动画
- `src/particles.js` 零GC点粒子池 • `src/audio.js` WebAudio合成 • `src/ui.js` HUD/界面 • `src/config.js` 数值+存档
