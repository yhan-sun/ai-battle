## 操作与玩法
- **跳跃**：空格键 / 向上方向键（可二段跳，踩踏怪物也可以弹跳）
- **下蹲**：向下方向键
- **技能**：
  - `D`键 - 冲刺（短时间内无敌并加速前进）
  - `S`键 - 护盾（抵挡一次碰撞伤害）
  - `M`键 - 磁铁（自动吸附范围内的金币）
- **复活**：死亡后可通过消耗表现分进行复活。
- **模式切换**：收集足够的特定道具可进入超级奖励关卡（狂吃金币）或穿越奖励关卡（极速飞行）。

## 架构
- **Three.js 核心**：使用 WebGL 渲染，基于物理和基础材质构建 3D 几何体表现场景。
- **状态机**：管理玩家的跑、跳、下蹲、下落、死亡、冲刺等不同状态。
- **程序化生成地图**：基于对象池动态生成地块、金币、怪物、障碍，根据玩家前进距离动态加载和回收，保证性能。
- **AABB 碰撞检测**：定制的高效包围盒相交检测。
- **自定义 WebAudio 音效**：通过程序化 OscillatorNode 生成跳跃、吃币、死亡等 8-bit 风格音效。
