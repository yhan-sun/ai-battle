# Google · Gemini 3.8 Flash High — 《天天炫跑 · CYBER DASH 3D》

> 参赛模型：Google Gemini 3.8 Flash High

基于 **Three.js + HTML5 / CSS3 / JavaScript (Vite)** 从零打造的 3D/2.5D 横版跑酷游戏，高度还原经典《天天酷跑》的节奏爽感与核心机制。

---

## 🚀 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 构建生产版本
npm run build
```

## 🎮 操作指南

| 操作 | 键盘按键 | 移动端 / 触屏按钮 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **跳跃** | `空格 (Space)` / `W` / `↑` / `K` | 右侧 **【跳跃】** 大按钮 | 支持一段跳、二段跳；装备特定坐骑可触发 **三段跳** |
| **下滑** | `S` / `↓` / `J` | 左侧 **【下滑】** 大按钮 | 贴地滑行，判定框变扁钻过低矮悬空尖刺；空中按下可 **极速俯冲突降** |
| **技能** | `F` / `L` / `E` | 中央 **【音速爆发】** 按钮 | 触发角色主动技能：极速冲刺 + 撞毁周边障碍 + 转化为高分金币（冷却18s） |
| **暂停** | `Esc` / `P` | 顶部 **【⏸️】** 按钮 | 随时暂停与恢复游戏 |
| **音效** | 点击顶部按钮 | 顶部 **【🔊/🔇】** 按钮 | 实时开启/静音音效与BGM |

## 🌟 核心机制与玩法特色

### 1. 坐骑系统 (Mount System)
- **机械炎豹 (Cyber Panther)**：拥有强劲仿生四肢，赋予角色 **三段跳能力**，并提供 **表现分 +25%** 加成。
- **极速战车 (Hyper Hoverbike)**：悬浮反重力涡轮战车，**滑行时具备冲撞能力**（直接撞碎障碍物），同时所有冲刺道具持续时间延长 50%。
- **糖果飞龙 (Candy Wyvern)**：萌系甜心飞龙，自动将部分金币转化为稀有彩虹糖果宝石（+500分），金币得分收益 **+30%**。

### 2. 宠物系统 (Pet System)
- **炽焰幼龙 (Flame Drake)**：盘旋在角色上方，每隔 8 秒喷射一枚高速烈焰火球，轰碎前方行进路线上的障碍物并掉落奖励之星。
- **波波精灵 (Bubble Sprite)**：周期性为角色生成护盾或磁铁水泡，提升生存容错率。
- **小飞碟 (UFO Drone)**：持续发射磁力牵引光束，吸附金币，并使 **超级奖励能量积攒速度提升 25%**。

### 3. 双重特殊奖励关卡机制（真正的多重独立场景）
- **超级奖励模式 (Super Reward Realm - 云端金币乐园)**：
  - 收集金币与踩怪持续为超级能量槽充能（0% ~ 100%）。
  - 满格后瞬间触发升天过场，角色乘金色光束飞升至高空云端天堂！
  - 独立场景：粉金祥云路段、巨大彩虹拱门、金币心形阵列与波浪矩阵。
  - **表现分 300% 狂欢加成**，持续 12 秒。结束后安全降落回主赛道，并附带 3 秒无敌保护期。
- **穿越奖励模式 (Dimension Rift Realm - 异次元赛博时空)**：
  - 主赛道上随机出现时空漩涡裂隙门（Portal Gate）。
  - 角色碰撞进入后，瞬间穿梭至高速赛博霓虹隧道。
  - 独立场景：荧光网格跑道、脉冲激光环廊、超光速星线穿梭。
  - 享受 **低重力漂浮大跳** 与 **超高速冲刺**，沿途铺满稀有异次元水晶与彩虹钻石（+1000 ~ +2000分）。

### 4. 障碍物与踩怪机制 (Monster Stomping)
- **地刺 (Ground Spikes)**：常见危险尖刺，需精准起跳避让。
- **悬空转锯/吊刺 (Hanging Saw)**：留有低矮通行空间，必须按下【下滑】滑行钻过！
- **萌萌怪 (Bouncing Monsters)**：
  - 从正面撞击会损失护盾或生命；
  - **在下落空中从怪物头顶踩过**，触发 **【踩怪弹跳 (Stomp)】**！不仅能借力弹至高空，还会触发踩怪连击（COMBO x1, x2, x3...），获得巨额表现分！
- **弹簧跳板 (Springboard)**：踩中后瞬间将角色弹射至超高空，直冲高难度金币弧线！

### 5. 丰富道具系统 (Powerups)
- 🧲 **金币磁铁 (Magnet)**：自动牵引大范围金币飞向角色。
- 🛡️ **能量护盾 (Shield)**：抵御一次致命碰撞伤害，附带碎盾无敌期。
- ⚡ **极速冲刺 (Sprint)**：无敌向前超音速飞行，直接撞碎一切沿途障碍。
- 🍄 **狂暴变大 (Giant)**：体型变大两倍，踩碎一切并享受双倍得分。
- ⭐ **双倍表现分 (Multiplier)**：短时间内表现分翻倍。

### 6. 无限程序化关卡算法 (Procedural & Solvable Generation)
- 基于运动学起跳抛物线 ($v_0, g$) 计算平台的间隙距离与高度跨度，保证所有地形 **100% 可通过**。
- 双层路径设计（高空富矿天桥路线 vs 地面平稳路线）。
- 内存优化机制：滚动离开视野后方的平台、金币与障碍物自动回收与销毁，保证稳定 60 FPS 流畅度。

### 7. 原生 Web Audio 音乐与音效合成引擎
- 无需依赖任何外部可能会失效的 MP3/WAV 资源，采用 Web Audio API 全程式实时合成：
  - 跳跃、多段跳、滑行摩擦、不同面额金币叮当声、踩怪卡通弹性声、碎盾音、过门穿越声、超级奖励号角！
  - 动态背景音乐系统：普通关卡街机电子律动、超级奖励欢快金币琶音、异次元赛博 Synthwave 律动，并随角色移速递增而自动加速！

### 8. 数据持久化 (LocalStorage)
- 自动保存历史最高分、最远奔跑距离、累计收集金币。
- 死亡提供一次 **5秒倒计时免费复活** 机会，重返赛道继续冲刺！
