## 操作与玩法
### 操作键位
- **跳跃 / 二段跳**：`Space` / `W` / `↑` 或 屏幕右下【跳跃】按钮
- **下蹲滑行 / 空中俯冲**：`S` / `↓` 或 屏幕左下【下蹲】按钮
- **星穹脉冲技能**：`E` / `F` 或 底部中央【脉冲】按钮（14秒冷却，瞬间净化前方障碍并转化为高分金币）
- **暂停 / 继续**：`Esc` / `P` 或 右上角【⏸️】按钮
- **音效 / 静音**：右上角【🔊】按钮

### 核心机制与奖励模式
1. **基础跑酷与递增速度**：
   - 随奔跑距离递增基础航速，考验反应与节奏掌控。
   - 地图无限程序化生成，严密保证跳跃跨度与障碍间距可通过。
2. **怪物踩踏机制 (Stomp)**：
   - 敌人带有顶部触发器，从空中踩中敌人头顶可借力反弹二段起跳、引爆敌人并获得高额表现分与能量加成。
3. **超级奖励模式 (Super Reward)**：
   - 收集金币与宝石蓄满 100% 超级能量后触发，切换至独立金色天界场景。
   - 包含密集 5x5 金币几何阵列、星辰矩阵与高倍表现分加成（3.5x），倒计时 10 秒后平滑重返主赛道。
4. **穿越异次元模式 (Warp Speed)**：
   - 收集穿梭能量满载后触发，进入超光速异次元时空隧道。
   - 视觉呈现动态高光粒子与广角畸变（FOV 90°），穿过光环获得连续 5000 分冲刺狂欢，持续 8 秒。
5. **坐骑与宠物系统**：
   - **光刃迅猛龙 (Mount)**：提供坐骑骑乘奔跑动作、双翼展开二段跳跃，并可为角色吸收 1 次致命伤害抵消坠毁。
   - **量子浮游机 (Pet)**：跟随玩家身边漂浮环绕，共鸣自动引力吸附周边金币。
6. **道具系统**：
   - **量子磁铁 (Magnet)**：大范围强力吸引金币与宝石（持续 12s）。
   - **能量护盾 (Shield)**：吸收 1 次伤害，破裂时产生护盾震爆（持续 18s）。
   - **超能冲刺 (Sprint)**：全速冲刺并处于无敌状态，撞碎沿途一切障碍（持续 6s）。
7. **死亡复活与最高分存档**：
   - 意外失足提供 1 次紧急量子护盾复活机制（3秒倒计时），复活后自带 3.5 秒无敌。
   - 成绩、历史最高表现得分与累积金币持久化保存在本地 `localStorage`。

## 架构
- **渲染与视觉 (Three.js WebGL)**：纯代码程序化构建 3D 赛博奔跑者、光刃坐骑、浮游宠物、各式赛博障碍与多层视差立体都市背景；动态着色器粒子系统（运行烟尘、滑行摩擦火花、二段跳跃光环、爆炸碎片、光速拉丝）。
- **音频系统 (Web Audio API)**：100% 纯代码合成音效与多音轨动态自适应 BGM，无任何外部音频资源加载延迟，根据常态/超级奖励/异次元模式无缝切换节拍与音色。
- **状态机与物理体系**：完整的解耦状态机（`RUNNING`、`JUMPING`、`DOUBLE_JUMPING`、`SLIDING`、`STOMPING`、`SUPER_REWARD`、`WARP_REWARD`、`PAUSED`、`GAMEOVER`），结合精准 AABB 碰撞盒与自适应地面高度查询。
