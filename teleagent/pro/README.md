## 核心机制
- **无限程序化生成**：跑道按需延伸，障碍间距保证随机地图必定可通过
- **奖励关真正切换**：超级奖励有独立浮空平台、金币阵列与倍率时间限制；穿越奖励切换为独立高速太空隧道（粒子轴向光速运动），非简单换背景
- **手感优化**：土狼时间（Coyote Time）、跳跃预输入（Buffer）、坐骑尾焰脉动、宠物绕飞
- **视听反馈**：程序化 WebAudio（踩踏 / 金币 / 冲刺 / 受伤 / BGM）、镜头震动、粒子火花、视差城市与星点
- **性能**：粒子对象池、地形与障碍回收剔除（Cull）
