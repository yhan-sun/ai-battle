# 星轨冲刺 · NEON SPRINT

一个不依赖原作资源的 Three.js 3D/2.5D 横版跑酷游戏。所有角色、障碍、坐骑、宠物、金币和奖励场景都由 Three.js 几何体程序化生成。

## 运行

```bash
npm install
npm run dev
```

然后打开 Vite 输出的本地地址。

## 操作

- `Space` / `↑` / `W`：跳跃，空中再次按下可二段跳
- `↓` / `S`：下蹲，穿过低空闸门
- `Shift`：冲刺，短时间高速并穿透障碍
- `E`：磁铁，自动吸附远处星币
- `Q`：护盾，生成短时间防护层
- `P` / `Esc`：暂停/继续
- 移动端可直接使用右下角跳跃、下蹲和技能按钮

## 玩法结构

- 主赛道由带有平地、缺口、阶梯、低空闸门、箱体、尖刺、可踩踏敌人和能力道具的分段无限生成。
- 距离推进会逐步增加速度；滑板和伙伴分别提供速度、金币价值与近距离吸附增益。
- 经过奖励门会切换到真正独立的 `超级奖励` 或 `穿越奖励` 场景。两个场景都有自己的赛道、金币阵列、计时器、倍率、装饰和高速节奏，结束后回到主赛道并保留本局进度。
- 撞击后可使用一次星核复活；结算页保存表现分、累计星币和最高分到 `localStorage`。
