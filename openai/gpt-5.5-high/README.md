## 操作与玩法
- `Space` / `W` / `↑`：跳跃，空中再次触发为二段跳
- `S` / `↓`：下蹲，躲过高位横杆
- `A/D` 或 `←/→`：三条近景跑道切换
- `E`：释放技能，获得短时冲刺、磁铁与无敌窗口
- `P` / `Esc`：暂停或恢复
- 触屏：底部按钮支持跳跃、下蹲、技能，画布左右区域可换道
- 收集金币增加表现分、连击与能量；磁铁吸附金币，护盾抵挡撞击，冲刺可破障
- 踩踏怪物会反弹并加分；撞击障碍后可消耗本局能量复活一次
- 超级奖励：进入独立金色奖励状态，金币阵列、倍率、倒计时结束后返回主赛道
- 穿越奖励：进入高速星门场景，速度、倍率、雾色和生成节奏都会切换，结束后回到主赛道
- 最高分使用 `localStorage` 保存

## 架构
- `index.html`：HUD、开始/暂停/复活/结算界面与触屏控件
- `src/styles.css`：响应式暗色 UI、HUD、屏幕面板和触屏按钮
- `src/main.js`：Three.js 场景、状态机、实体系统、碰撞、程序化地图、奖励模式、粒子、音效与输入
- `scripts/dev-server.mjs`：零依赖本地静态服务器，支持 `--host` 和 `--port`
- `scripts/build.mjs`：零依赖构建，把可运行静态文件复制到 `dist/`

核心状态分为 `normal`、`super`、`crossing`；主循环按顺序更新计时器、玩家、实体、粒子、背景、镜头和 HUD。实体使用轻量 AABB 检测，地图按 chunk 无限生成并及时回收，角色、坐骑、宠物、障碍、金币、传送门和特效全部由 Three.js 几何体与程序化材质生成。
