## 运行

```bash
npm install
npm run dev
```

开发服务器默认位于 `http://127.0.0.1:5173`。也可以指定端口：

```bash
npm run dev -- --host 127.0.0.1 --port 5176
```

构建静态站点：

```bash
npm run build
npm run preview
```

安装脚本会将 `three@0.170.0` 的官方 ES module 复制到 `src/vendor/`，使构建产物不依赖运行时 CDN。

## 操作与玩法

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 开始 / 再来一局 | `Enter` | 界面按钮 |
| 跳跃 / 二段跳 | `Space`、`W`、`↑` | 跳跃按钮 |
| 下蹲滑行 / 空中速降 | `S`、`↓` | 按住下蹲 |
| 共鸣技能 | `Shift`、`X`、`E` | 技能按钮 |
| 暂停 / 恢复 | `P`、`Esc` | HUD 暂停按钮 |
| 复活 | `R` | 复活按钮 |

角色会自动向前奔跑，速度随距离递增。收集光币、踩踏怪物和摧毁障碍会增加表现分与连击；连击每 12 层提升一次倍率。低门必须下蹲，尖刺障碍与沟壑需要跳跃，怪物可以从上方踩踏。

### 坐骑与宠物

- **折光鳐坐骑**：通过坐骑拾取或共鸣技能激活。它会切换独立骑乘动画、降低空中重力，并可替角色抵消一次伤害。
- **光核伙伴**：始终跟随角色，每隔一段时间会脉冲扫描并代收前方最近的一枚光币；HUD、合成音效和粒子会给出反馈。

### 道具与技能

- **潮膜护盾**：抵消一次碰撞。
- **引潮磁场**：把前方光币拉向角色。
- **浪尖冲刺**：大幅提速并撞碎障碍和怪物。
- **折光共鸣**：带冷却的主动技能，同时启动冲刺、磁场、护盾和坐骑，并开启额外得分倍率。

### 奖励场景

- **超级奖励 · 光珊瑚庭**：达到里程阈值后，清空主航道并重建独立庭院场景、连续金币阵列、拱门和奖励平台。持续 12 秒，基础倍率 ×3，结束后重新生成安全主航道。
- **穿越奖励 · 相位洋流**：切换为独立高速隧道，重建相位环、流光轨道和波形金币路线，同时改变镜头透视并强制高速。持续 9.5 秒，基础倍率 ×2，结束后恢复主航道速度与场景。

### 死亡、复活与存档

每局有一次「回潮火种」。致命碰撞或跌入沟壑后会进入 8 秒复活倒计时；复活会生成安全航道并给予短暂无敌与护盾。结算页展示表现分、距离、光币与最高连击；最高分通过 `localStorage` 保存。

## 架构

项目采用浏览器原生 ES Modules，不依赖 UI 框架：

- `src/core.js`：确定性随机数、跑者状态机、物理与计分模型、技能/道具/复活、奖励模式状态，以及可通过的分段关卡规划器。
- `src/main.js`：Three.js 渲染、角色骨架动画、世界与主题重建、碰撞、对象池、程序化音频、固定容量粒子池、镜头、输入、HUD 和浏览器冒烟测试。
- `src/styles.css`：响应式 HUD、开始/暂停/复活/结算界面和触屏控制。
- `scripts/vendor.mjs`：把 npm 安装的官方 Three.js 模块固定到项目运行目录。
- `scripts/dev.mjs`：零框架静态开发服务器，支持 `--host` 与 `--port`。
- `scripts/build.mjs`：校验必要输入并生成独立 `dist/`。
- `tests/core.test.mjs`：使用 Node 内置测试运行器验证核心状态和 2,500 个程序化分段样本。

### 关键工程机制

1. **状态机分离**：`RunnerModel` 不依赖 DOM/Three.js，因此跳跃、冷却、复活、奖励切换和得分倍率可以确定性测试。
2. **可通过地图**：关卡从有反应缓冲的策划模板中随机组合；沟壑宽度、障碍间距和安全入口/出口都有硬约束，金币弧线同时承担动作提示。
3. **真实场景切换**：两个奖励关都会销毁当前活动分段、重建主题背景与赛道图、采用不同生成器和镜头，不是简单换色。
4. **资源复用**：材质与基础资源复用，硬币、障碍、怪物和道具通过对象池回收；粒子使用固定容量 `BufferGeometry`，避免每帧分配。
5. **程序化表现**：角色、坐骑、宠物、地形、障碍、粒子和音频全部由代码生成，无外部模型、美术图或预录音频。
6. **无 Playwright 冒烟测试**：`?smoke=1` 会在真实浏览器中执行开始、二段跳、下蹲、技能、暂停、复活、两种奖励场景和本地存档检查，并将 JSON 结果写入 `#smoke-result` 与 `<html data-smoke>`。
