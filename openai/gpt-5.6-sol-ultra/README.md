# OpenAI · GPT-5.6 Sol Ultra — 霓渊逐光

《霓渊逐光》是一款完全由代码、CSS、Three.js 几何体与 WebAudio 合成的原创 3D/2.5D 横版跑酷游戏。玩家在云海、地下晶脉和独立奖励界域间自动奔跑，通过二段跳、下蹲、技能、冲刺、坐骑与宠物机制维持高速连击。

- 踩中怪物会反弹并加分；正面碰撞、路障或坠落会消耗护盾，之后进入可复活一次的倒地状态。

- “奖励巡游”是完整机制的快速体验路线，不是展示动画：它依次进入并实际运行三套生成器、场景与计时器，再返回无限远征。

### 三类奖励模式

- **超级奖励**：切换至金粉云海独立场景，运行专用三排波形金币阵列与礼盒生成器，10 秒限时，表现倍率显著提升。
- **穿越奖励**：清空常规地图并切换至独立高速时空隧道；环形隧道、速度线、专用双层金币波和 34+ u/s 速度均由独立逻辑驱动，9 秒后返回。
- **云巅奖励关**：进入独立云台关卡生成器，包含可通过的小裂隙、上下云台、金币弧线与礼盒雨，12 秒后恢复当前无限远征地形。

## 架构

- `src/main.js`：单一游戏入口与显式 `menu / playing / paused / downed / results` 生命周期，以及 `normal / super / rift / bonus` 奖励模式状态机。
- 程序化关卡以 24 单位安全块无限前推，使用平地、受限裂隙、台阶、上下层云台和怪物节奏模板；裂隙宽度与障碍间距均小于角色跳跃能力，避免随机生成死局。
- 碰撞采用横版 AABB、前后帧落点检测、平台支撑面和怪物顶部判定；物理用 120 Hz 固定步长，渲染使用 `requestAnimationFrame`。
- 金币、危险物、道具和粒子使用对象池；Three.js 几何体与材质在实例间共享，像素比上限为 1.75，Three.js 构建产物拆成独立缓存 chunk。
- 角色由程序化几何体组合，奔跑摆臂、步态、起跳、二段跳、下蹲、冲刺、围巾、坐骑与宠物跟随均实时动画。
- `src/audio.js` 惰性创建 WebAudio 图，包含 13 种程序化音效和会随速度/奖励模式变化的合成节奏，不含任何录音素材。
- 最高分、最远距离、累计金币和静音设置使用 `localStorage` 保存；隐私模式下存储失败会安全降级，不影响游戏。
