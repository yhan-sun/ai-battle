## 运行
需要 Node.js 20.19+ 或 22.12+（本次使用 24.13.0）以及支持 WebGL 2 的现代浏览器。

```bash
cd openai/gpt-6-astra-max
npm install && npm run dev
```

生产构建：`npm run build`；预览：`npm run preview`。使用相对资源路径，可部署到子目录。首次加载后游戏运行不依赖外部资源请求。

## 操作与玩法
| 操作 | 键盘 / 触屏 |
| --- | --- |
| 开始 / 再来一局 | 开始按钮，或空格 / Enter |
| 跳跃 / 二段跳 | 空格、↑、W；右下跳跃按钮或点击场景 |
| 下蹲 / 空中快速下落 | 按住 ↓ / S，或左下下蹲按钮 |
| 邮光冲刺技能 | X 或冲刺按钮；100 蓄能可用 |
| 暂停 / 恢复 | P / Esc 或右上暂停；切换窗口自动暂停 |
| 声音 | 右上音符开关，首次操作后解锁 WebAudio |

自动奔跑随累计距离从 9 m/s 增至最高 17 m/s。浮岛路段包括平地、4.2 米缺口、错层地面、低拱门、货箱与云团怪。货箱需要跳过，低拱门需要下蹲，从上方落在怪物上可踩踏弹起并加分。宠物小信标自动拾取近处星币，连续收集提升连击与表现分。

道具：护盾持续 14 秒并抵消一次碰撞；磁铁持续 12 秒、扩大拾取半径；滑翔坐骑持续 16 秒，提高跳跃与普通速度，并能挡下一次撞击；冲刺道具持续 4 秒。主动技能持续 3 秒，消耗 100 蓄能，提供高速飞行、破障与磁吸；能量随时间与星币恢复。保护状态可从坠落中救回安全平台。

超级奖励：普通航线收集 28 枚星币后，安全落地自动进入独立云顶金币航线，12 秒、3 倍星币与踩踏表现分。穿越奖励：经过星门实际切入 30 m/s 的立体星环高速航道，9 秒、5 倍表现分，可跳跃或下蹲改变收集高度。两种模式都有独立路线坐标、金币阵列和冻结/计时逻辑，结束后恢复原航线附近的安全位置，清除周边危险并给予 3 秒保护。基础距离分为每米 5 分，倍率作用于金币与踩踏得分。

每局有一次免费信标救援；首次死亡可复活或直接结算，复活后再次死亡直接结算。结算持久化最高分、最远距离、总星币、局数与声音偏好。存档失败时仍能玩，会提示记录仅在当前页面内保留。刷新页面不续接未完成的一局。

## 架构
- `src/simulation.js`：独立于浏览器的固定 120 Hz 模拟；主流程 menu / running / paused / dead / ended 与普通 / 超级 / 穿越模式分离。包含 AABB 碰撞、下降踩踏判定、两段跳、效果计时、复活与安全返回。
- 程序地图使用可复现种子与受约束模板；最低速度的单跳水平范围超过 7.7 米，坑宽 4.2 米，危险决策点保持足够间距。普通速度硬上限 17 m/s。世界只保留玩家附近的路段。
- `src/renderer.js`：Three.js 正交视角、几何角色骨架、滑翔坐骑、宠物、视差浮岛与天空/地下/奖励场景；金币和粒子使用 InstancedMesh，几何体与材质共享缓存，移除离屏实体，限制像素比，窄屏关闭动态阴影。
- `src/main.js` / `src/style.css`：DOM HUD、开始/暂停/救援/结算、键盘与 Pointer Events、窗口失焦暂停、响应式触屏控件、界面反馈。开发模式有只读快照及受控验证入口，生产构建移除调试入口。
- `src/audio.js`：手势解锁的程序化 WebAudio 合成音；`src/storage.js`：版本化本地记录与存储失败降级。
- `tests/simulation.test.mjs`：可执行逻辑与地图通行检查；`tests/browser-check.mjs`：使用已有 Chrome 的 DevTools Protocol 验证实际页面，零 Playwright 依赖、零截图。
