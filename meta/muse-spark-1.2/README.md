## 操作与玩法
- **移动**：A/← 向左切道 · D/→ 向右切道（3 赛道平滑插值）
- **跳跃/二段跳**：空格 / ↑ / W / 点击右侧 / 上滑（支持土狼时间 0.13s 与跳跃缓冲 0.14s）
- **下蹲/滑铲/空中速降**：↓ / S / 点击左侧 / 下滑（地面滑铲 0.62s，空中俯冲加速落地）
- **冲刺技能**：F / Shift / ⚡按钮（3s 无敌高速，摧毁障碍，冷却 11s，可跨奖励关衔接）
- **暂停/静音**：P/Esc 暂停 · M 静音 · 觸屏按鈕

**玩法循环**
- 自动奔跑，速度 11→28 随距离递增（穿越关 1.28×、冲刺 +9），表现分 = 距离×10 + 金币×100×倍率 + 踩怪×500
- 障碍：尖刺(跳) / 闸门(蹲下滑过) / 立柱(切道) / 怪物(踩头消灭+反弹，踩空即死)
- 道具：🧲磁铁 8s（半径 7，宠物常驻小磁铁 2.8）· 🛡护盾 10s · 🚀冲刺 · ★星兽坐骑（抵挡一次，14s）
- 坐骑/宠物：主页可开关；宠物蓝光悬浮跟随，发光圆环动画；坐骑为星角兽骑乘，改变碰撞高度与受击逻辑
- **SUPER 能量**：每吃 28 金币攒满 → **超级奖励** 独立金色场景（金色地面/雾、3 赛道金币阵列每块 30 枚、x3 倍率、无敌、9s，到点闪白返回+1.6s 无敌）
- **穿越奖励**：随机 ◎光门（每块约 7% 概率）→ **穿越关** 真正切换至星际隧道（圆柱隧道纹理滚动+光环+星点流、高速 1.28×、专属稀疏立柱与密集金币、x2 倍率、8s，结束闪白返回）
- 受击：护盾>坐骑>无敌 优先级抵挡，否则死亡；死亡可复活 1 次（3s 无敌冲刺），倒计时 5s
- 存档：最高分/最远/最多金币 localStorage，开始/暂停/结算/新纪录全套 UI

## 架构
- `src/main.js` 启动、音频解锁、输入分发
- `src/game.js` Game 状态机（MENU/PLAYING/PAUSED/OVER × normal/super/cross）、计分、速度、碰撞、磁铁、奖励切换、镜头 FOV/震动、雾色切换
- `src/level.js` 无限分块循环（12 块×32m）+ 对象池（障碍/金币/装饰回收）+ 主题轮换（city/cave/sky）+ 奖励关独立生成（超级金币阵/穿越隧道）+ 最小间距与“跨距障碍不连续”保证可通过
- `src/player.js` 程序化角色（胶囊+球头+挑染+红框眼镜+围巾）+ 宠物跟随 + 星兽坐骑 + 物理（重力 30、土狼、缓冲、滑铲、俯冲、双跳）+ 跑跳蹲骑乘动画
- `src/particles.js` 零 GC 粒子池（Mesh 球池 180 + Points 点池 120）+ 金币/受击/拖尾特效
- `src/audio.js` WebAudio 合成（跳跃/二段跳/金币/冲刺/护盾/踩怪/传送/超级进入/死亡 + 程序化 BGM 低通+底鼓）
- `src/ui.js` HUD/开始/暂停/结算、能量条、Buff、模式横幅、技能冷却、触屏与键盘/手势
- `src/config.js` 数值与存档
- `src/style.css` 玻璃拟态 HUD、渐变 CTA、视差与光效
